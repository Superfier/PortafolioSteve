# ⚙️ Instalación

### Clonar repositorio

```bash
git clone https://github.com/Superfier/PortafolioSteve.git
```

### Entrar al proyecto

```bash
cd PortafolioSteve
```

### Instalar dependencias

```bash
npm install
```

### Ejecutar en desarrollo

```bash
npm run dev
```

### Generar versión de producción

```bash
npm run build
```
